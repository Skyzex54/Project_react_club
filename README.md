**AI Dev Community Website** is a collaborative frontend project developed for a student club focused on Artificial Intelligence.


### Key Features

- **Home** — Introduction to the AI Dev Community and its activities
- **About** — Overview of the club, its mission, and objectives
- **Members** — Presentation of the club members and team
- **Contact** — Contact section for inquiries and communication
- **Login & Register** — Authentication interface for users
- **Routing System** — Navigation between pages using React routing
- **Responsive Design** — Optimized for different screen sizes
- **Modern UI & Animations** — Interactive elements, transitions, and visually distinct sections

> The project is built with **React** and **Tailwind CSS**, focusing entirely on the **frontend** and featuring a modern, responsive, and visually engaging interface with smooth animations and colorful sections, while serving as a collaborative team project to practice modern web development, UI design, React components, and teamwork.
